# Diagram prompts

Active human-authored diagram requests live in this directory and start from
[`TEMPLATE.md`](TEMPLATE.md). Each prompt is private authoring input: it may cite internal
evidence, but those references must not be copied into a future public artifact.

Superseded or inactive requests belong in [`shelved/`](shelved/). Files in that directory
are context only and must not drive generation unless the user explicitly reactivates them.
